# Agenda Virtual

Este proyecto contiene dos aplicaciones principales:

- **Backend**: API construida con Laravel.
- **Frontend**: Interfaz de usuario construida con React.

## Estructura del Proyecto

```
/
├── backend/    # Código fuente de Laravel
├── frontend/   # Código fuente de React
├── .gitmessage # Plantilla para mensajes de commit
└── .vscode/    # Configuración del editor
```

## Configuración de Git

Se ha configurado una plantilla para los mensajes de commit siguiendo el estándar de **Conventional Commits** con Emojis.

Para usar la plantilla en línea de comandos:
`git commit` (se abrirá el editor con la plantilla)

En VS Code, las extensiones sugeridas y la configuración ayudarán a seguir este formato.
